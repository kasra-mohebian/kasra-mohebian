# Hi, I’m Kasra

I’m a backend developer interested in reliable APIs, data processing and systems programming. I enjoy tracing how a system works, testing assumptions and making the results understandable.

## Projects

- **[C++ systems programming](https://github.com/kasra-mohebian/cpp-systems-programming)** — C++20 data structures, RAII, expression trees and concurrency, with standalone tests and examples.
- **[RAM, HBM & CXL memory study](https://github.com/kasra-mohebian/cxl-memory-study)** — C++ memory experiments, recorded measurements and a literature review. The corrected tools are distinguished from the historical results.
- **[AI tools and developer trust](https://github.com/kasra-mohebian/ai-developer-trust)** — A reproducible Python analysis of Stack Overflow survey data, with explicit respondent groups and tested category mappings.
- **[SocialCompass](https://github.com/kasra-mohebian/team-communication-analyzer)** — A group coursework project combining NLP and network analysis. The public version includes an offline fictional-data demo and selected aggregate results.
- **[Music and coding focus](https://github.com/kasra-mohebian/music-and-coding-focus)** — A critical literature review that separates verified findings from limited-access evidence.

These repositories collect completed coursework and research explorations. They show the code, evidence and limitations behind each project.
